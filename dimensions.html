How the shape is computed

Check by box counting

The program scatters points over the shape, covers it with grids of boxes of side ε = 1/2, 1/4, 1/8 and so on, and counts the boxes touched. If N(ε) ∝ ε−D, those counts fall on a line of slope D. Only grids coarse enough for the points to fill are used (cyan). For the swept shapes the chart measures the profile curve, then adds the sphere's dimension, which is exact because the sphere is smooth.
